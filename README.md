# Edubat : téléchargements

Ce dépôt contient uniquement les versions téléchargeables d'Edubat, application de visualisation de maquettes
numériques de bâtiments (IFC) développée par NOBATEK. Le code source n'est pas public.

## Télécharger

Les versions sont disponibles dans l'onglet [Releases](../../releases) :
[dernière version](../../releases/latest).

Chaque version comprend :

- l'application pour macOS et/ou Windows (archives `.zip`) ;
- `SHA256SUMS.txt`, les sommes de contrôle permettant de vérifier l'intégrité des téléchargements ;
- `THIRD_PARTY_NOTICES.md`, les licences des composants tiers intégrés à l'application.

## Utilisation

L'utilisation d'Edubat nécessite un compte Edubat. Edubat est un logiciel propriétaire de NOBATEK : tous droits
réservés.
